# System Call Lab

In this lab, you'll add code to `xv6` to show the system calls occurring in the system, and then you'll implement a new system call and a program that uses it.

The lab manual for this lab is [online](https://docs.google.com/document/d/1-xRs9h5rhoySVncboyInrIn-1wsYb8_c/edit?usp=sharing&ouid=102414386289986142803&rtpof=true&sd=true).
